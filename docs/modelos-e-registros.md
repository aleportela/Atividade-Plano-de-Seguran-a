# Modelos e registros

Os modelos abaixo devem ser preenchidos pela instituição e guardados em local apropriado. Não inserir senhas, tokens, chaves, dados pessoais desnecessários ou informações detalhadas de acesso neste repositório público.

## Anexo A — Checklist de diagnóstico inicial

Marcar cada item como **Atendido**, **Parcial**, **Não atendido** ou **Não aplicável**. Para itens não atendidos, registrar responsável, prazo e evidência esperada.

| Nº | Pergunta | Status / evidência / responsável |
|---:|---|---|
| 1 | Existe inventário atualizado de computadores, servidores, notebooks, equipamentos de rede e softwares? | |
| 2 | Os números de professores, funcionários e usuários dos sistemas estão identificados? | |
| 3 | Todos os usuários possuem contas individuais? | |
| 4 | Contas administrativas e acessos remotos utilizam MFA quando disponível? | |
| 5 | Existe processo documentado para admissão, mudança de função e desligamento? | |
| 6 | As versões do Windows e dos servidores estão em suporte e atualizadas? | |
| 7 | Todos os computadores possuem proteção antimalware/EDR gerenciada? | |
| 8 | Os notebooks que armazenam dados confidenciais possuem criptografia de disco? | |
| 9 | Os três laboratórios estão isolados da rede administrativa e dos servidores? | |
| 10 | Existe rede separada para visitantes e dispositivos pessoais? | |
| 11 | O acesso ao data center é restrito e registrado? | |
| 12 | Os backups são criptografados e possuem cópia offline ou imutável? | |
| 13 | Foi realizado teste de restauração nos últimos 90 dias? | |
| 14 | O site e o aplicativo possuem fornecedores, contratos e responsáveis identificados? | |
| 15 | Os fornecedores críticos têm obrigação contratual de notificar incidentes rapidamente? | |
| 16 | Existe inventário das operações de tratamento de dados pessoais? | |
| 17 | Existe aviso de privacidade claro e canal de contato para titulares/responsáveis? | |
| 18 | Existe procedimento de resposta a incidentes conhecido pelos colaboradores? | |
| 19 | Os funcionários receberam treinamento de segurança e privacidade no último ano? | |
| 20 | Existe plano de continuidade para indisponibilidade de internet, sistema acadêmico ou data center? | |
